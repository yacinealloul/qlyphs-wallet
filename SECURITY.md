# Security

Report a vulnerability, or a keys.qlyphs.com file whose hash does not match a release, privately
through this repository's **Security** tab → **Report a vulnerability**. Please do not open a public
issue for it.

In scope: the wallet code in this repository (`apps/keys`, `apps/extension`, `packages/provider`
and the shared modules they import) and what https://keys.qlyphs.com serves.

How to check a release yourself: [apps/keys/README.md, Verify a release](apps/keys/README.md#verify-a-release).
